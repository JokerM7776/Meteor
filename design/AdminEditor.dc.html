Title

A 150-line Markdown parser, line by line

Summary

Headings, emphasis, links, lists and fenced code — plus the table of contents, extracted in the same pass.

## Why write your own

Composer packages are excellent, but this blog
needs a small slice of Markdown, and I want to
read every line that touches my content.

## The block pass

The parser splits the text on blank lines and
looks at the first characters of each block:
`#` for headings, `-` for lists, three backticks
for code.

### Headings become anchors

Each `##` and `###` gets an id made from its
text, and is pushed onto the TOC list at the
same time.

## The inline pass

Bold, italic, inline code and links are four
regular expressions, run in that order.
